# Changelog

## 0.23.1 / menu 3.6 - 2026-10-28

First public package of the existing AI 0.23.1 and menu 3.6 sources.

- Added portable game-folder discovery and Steam launching.
- Added a guided, manifest-checked installer, update backups, and guarded removal in a dedicated mod subfolder.
- Added installation, controls, defaults, compatibility, and contributor documentation.
- Excluded game files, extracted native scripts, saves, private evidence, and logs.

Gameplay in the included build retains AI 0.23.1's manual-only mission call policy, preparation recovery, and explicit job inheritance. Menu 3.6 retains F6/F7 tap/hold deployment controls. Their latest full physical playtest is still pending; packaging did not change gameplay Lua.
